# Movie App React JS

This is a React application for browsing movies that I built by following online tutorials and adding my own features.

## Project Description

This app allows users to search for movies, view detailed information, and keep up with the latest releases.

## How to Run the Project

In the project directory, you can run:

### `npm start`

Runs the app in development mode.  
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder. The build is optimized for best performance.
